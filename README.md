# Diploma Thesis Management System

A web-based application designed to streamline the process of managing diploma theses within a university department.

## Features
* **Students:** Browse available topics, submit applications, and track progress.
* **Professors:** Create and edit thesis topics, manage student applications (accept/reject).
* **Secretariat (Admin):** System oversight, user account management, and global settings.

## Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP
* **Database:** MySQL

## How it Works
The application uses a role-based access control system to ensure that Students, Professors, and Administrators have access to their respective functionalities, ensuring a smooth workflow from thesis announcement to completion.
